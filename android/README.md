# Kinesis for Android

A full-screen WebView wrapping `kinesis3d.html`. The game already ships its own
touch controls (stick, Jump, Dash, Push, Force, Mode) and asks for landscape, so
the app adds only what a browser tab cannot: landscape lock, immersive
full-screen, and keeping the screen awake.

    ./android/build.sh        # -> android/build/kinesis.apk

## Requirements

- A JDK (21 works)
- Android SDK with `build-tools;34.0.0` and `platforms;android-34`
- `ANDROID_HOME` pointing at the SDK (defaults to `/opt/android-sdk`)

Install the SDK pieces with:

```bash
sdkmanager --install "platforms;android-34" "build-tools;34.0.0"
```

## Why there is no Gradle here

The app is one Java file and one HTML asset. The Android Gradle Plugin would
download a dependency tree larger than the game to run the same
`aapt2` → `javac` → `d8` → `zipalign` → `apksigner` sequence `build.sh` runs
directly. The script is ~60 lines and has no network dependency beyond the SDK.

`build.sh` rebuilds `kinesis3d.html` from `game/` before packaging, so the APK
can never ship a stale bundle — that is the one mistake this layout could
otherwise make silently.

## Installing on a phone

The APK is signed with a local debug key, so Android treats it as a sideload:

1. Copy `kinesis.apk` to the phone.
2. Open it, and allow installs from that app when prompted
   (Settings → Apps → Special access → Install unknown apps).
3. Needs Android 7.0 (API 24) or newer, and a device with WebGL — anything
   from the last decade.

The key lives at `android/build/debug.keystore` and is **not** committed. It is
generated once and then reused, because Android refuses to install an update
signed by a different key: delete it and the next build can only be installed
after uninstalling the old app.

## Layout

| Path | What it is |
|---|---|
| `AndroidManifest.xml` | package, landscape lock, WebGL feature requirement; requests no permissions |
| `java/com/kinesis/game/MainActivity.java` | the WebView host |
| `res/values/` | app name, theme, background colour |
| `res/mipmap-*/` | launcher icon, generated by `make_icon.py` |
| `make_icon.py` | draws the icon at 4x and downsamples, so the blades keep clean edges |
| `build.sh` | the whole build |

## What is not covered

The build is verified by structure (manifest, dex, signature) and by loading the
asset **extracted from the built APK** in a touch-enabled, phone-sized Chromium.
It has not been booted on a real device or emulator from this repo's CI, since
that needs KVM. The WebView wrapper is the only part not exercised that way.
